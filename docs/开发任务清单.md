# BRD 管理系统开发任务清单

对应设计说明书 1.1。所有实现项目前均未完成，仅账号与上传版本管理属于本期范围。

## 第一批 账号与文档入口

- [ ] 初始化前后端项目，锁定依赖，配置独立数据库与文件持久卷。
- [ ] 实现管理员创建账号、登录、退出、首次强制改密及本人修改密码。
- [ ] 实现角色配置、重置密码、停用和启用，撤销失效会话。
- [ ] 实现 ADMIN、UPLOADER、READER 权限及最后管理员保护。
- [ ] 实现共享文档列表、项目和批次筛选、文档详情及负责人转交。

## 第二批 上传与版本

- [ ] 实现 PDF 和 DOCX 上传、20 MB 限制、结构检查、安全扫描及隔离。
- [ ] 实现新文档与 V1 原子接收，上传失败不留下可见空文档。
- [ ] 实现新版本上传、修改说明、基于版本及上传者记录。
- [ ] 实现文档内递增序号、不可覆盖存储、摘要去重和请求幂等。
- [ ] 实现历史分页及原文件授权下载，下载名称包含编号和版本。
- [ ] 实现当前版与最新上传版分别展示，历史版明确提示。
- [ ] 实现负责人或管理员手动切换当前版，支持切回旧版及并发冲突提示。

## 第三批 可靠性与验收

- [ ] 实现上传进度、检查状态、取消、错误恢复及孤立文件清理。
- [ ] 实现上传、下载、当前版切换和账号管理操作日志。
- [ ] 验证上传期间账号停用、角色变化及负责人转交的最终鉴权。
- [ ] 配置 HTTPS、CSRF、会话、文件目录安全和磁盘告警。
- [ ] 完成设计说明书 AT01 至 AT16 验收。
- [ ] 完成数据库及文件一致性备份与恢复演练。

## 不在本期

审批与会签、在线编辑、模板管理、内容语义 Diff、分支合并、通知中心、格式转换和复杂发布流程。旧 UI 中相应操作不能直接进入本期开发。
