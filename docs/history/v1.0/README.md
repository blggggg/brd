## 设计基线

采用 Java 21、Spring Boot、Vue 3 与 MySQL 的模块化单体架构。项目、权限、结构化 BRD、不可变版本、评审审批、发布与变更构成第一期范围。具体框架补丁版本在实施时锁定。

使用独立数据库 `brd_management`、独立应用账号及迁移账号。不得直接复用 pet 项目的运行配置、数据库或密码。

后续目录约定：`backend/` 后端，`frontend/` 前端，`deploy/` 部署配置，`docs/` 设计文档。当前仅创建文档，不以空壳代码代表已完成系统。
