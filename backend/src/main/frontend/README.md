# BRD 原生前端

HTML + CSS + JavaScript（ES modules），不使用 Vue、React 或 TypeScript。Vite 仅用于开发服务和打包。

## 启动

后端监听 `127.0.0.1:8091`；在本目录运行 `npm ci`、`npm run dev`，访问 `http://127.0.0.1:5173/`。默认 `/api` 代理指向后端 8091。可通过 `BRD_API_TARGET` 指定测试后端。

## 功能

- 登录、首次修改临时密码、退出。
- 文档列表、标题/项目/批次搜索、分页、新建文档。
- PDF/DOCX 上传（20 MB）、处理状态、内容去重、上传状态恢复。
- 区分当前使用版和最新上传版；上传不自动切换当前版（V1 除外）。
- 下载历史版本和当前版、手动切换/回退、填写切换原因、操作历史。
- 编辑文档信息；管理员可变更负责人。
- 管理员创建账号、修改角色、启停、重置密码。上传者只可维护自己负责的文档，阅读者只可查看和下载。
- 无审批流程，无文件内容在线比较。

## 验证

`npm test` 执行前端单元测试；`npm run build` 检查语法并构建。

浏览器测试运行 `npx playwright test`，使用本机 Edge 无头模式，自动启动和关闭前端 5174、后端 8092（内存数据库、独立临时文件目录）。需要先构建后端 jar；可用 `BRD_TEST_JAR` 指定 jar 路径、`JAVA_HOME` 指定 Java 17。测试凭据仅用于隔离测试，不能用于实际部署。测试会修改测试账号密码并上传测试文档，不要连接真实业务库。

当前仅为本地开发配置，文件结构校验不等于完整病毒扫描；上线前须配置 HTTPS、独立强密码、数据库备份与 ClamAV。
